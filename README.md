### ⚡ What I'm building

<table>

<td width="50%" valign="top">

#### [Relaya](https://github.com/dhirajray-12/relaya)
**Integration reliability & control platform.**
Receives webhooks from third-party providers, verifies and stores every event, delivers them with retries, and helps you see and fix what breaks.

- 🛡️ Webhook gateway with signature checks + dedupe
- 🔎 Event explorer with search, inspect and replay
- 📐 Payload contracts that flag provider drift as incidents
- 🔧 Repair rules, alerts, OAuth connections, proxy & syncs

`Go` `PostgreSQL` `React` `WebSocket` `Prometheus`
